# Voorbeeld Portfolio Website

Dit is mijn tweede webdevelopment-project. Deze website heb ik gemaakt aan de hand van opdrachten die ik kreeg van AI.

Ik heb deze website gebouwd om extra te oefenen met HTML, CSS en responsive design. Daarnaast heb ik verschillende layouts, designs en interacties uitgeprobeerd.

## 🎨 Functionaliteit

- Een volledige portfolio-website opgebouwd met HTML en CSS.
- Responsive design toegepast voor verschillende schermformaten.
- Verschillende layouts gemaakt met Flexbox en Grid.
- Extra designs en interacties uitgeprobeerd.
- Verschillende onderdelen van een portfolio-website opgebouwd.

## 🛠️ Gebruikte technieken

- HTML5
- CSS3
- Responsive design
- Flexbox
- CSS Grid
- Git
- GitHub

## 📚 Wat heb ik geleerd?

Tijdens dit project heb ik vooral verder geoefend met het opbouwen van een volledige website.

Ik heb geleerd hoe ik een HTML-structuur beter kan opbouwen en hoe verschillende CSS-layouts samenwerken binnen een website. Ook heb ik beter leren begrijpen wat er gebeurt wanneer ik Flexbox en Grid gebruik om elementen op de pagina te positioneren.

Daarnaast heb ik geoefend met het maken van responsive websites, zodat de website goed werkt op verschillende schermformaten.

Tijdens dit project heb ik ook verder geoefend met Git en GitHub. Hierdoor leer ik steeds beter hoe ik mijn projecten kan beheren en online kan publiceren.

Ik maak regelmatig kleine projecten om mijn vaardigheden steeds verder te ontwikkelen en meer ervaring op te doen met het zelfstandig bouwen van websites.
